# Gestor de Tareas

Aplicación web sencilla para organizar pendientes diarios. Permite agregar tareas nuevas, marcarlas como completadas, filtrarlas por estado (todas, pendientes o completadas) y mantenerlas guardadas en el navegador aunque se cierre o recargue la página.

## Tecnologías utilizadas
- HTML5
- CSS3
- TypeScript
- Vite

## Cómo instalar y ejecutar
1. Clona este repositorio en tu computadora:
   ```bash
   git clone [https://github.com/mjsb05/gestor-tareas-js.git](https://github.com/mjsb05/gestor-tareas-js.git)
   cd gestor-tareas-js
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre en tu navegador el enlace local que aparece en la terminal (normalmente `http://localhost:5173`).
